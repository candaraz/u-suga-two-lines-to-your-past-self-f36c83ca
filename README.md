# Two Lines to Your Past Self

A make.fun entry for **Two Lines to Your Past Self**: a two-line warning sent back to a past self. Line one names one specific moment — tonight, before the trip, with the photos still un-backed-up on one phone. Line two traces the cause and effect: the phone lost in a Lisbon taxi by Friday, the dog gone by winter, and a lifetime of describing those photos from memory instead of showing them.

The program (`main.ts`, Node 22, standard library only) writes the warning, byte for byte, to `entry.txt` in the output directory on every run.
